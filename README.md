# TheGunshots

## 遊戲架構
遊戲世界採隨機生成，玩家可以創建房間（主機），並透過Peer.js讓其他玩家加入遊戲。在遊戲中，整個世界都是黑暗的，只有玩家眼前的一小片區域可見，牆壁阻擋光線照射，必須小心翼翼地在轉角中慢慢探頭，以免遇到突如其來地爆頭。
遊戲中的元素很簡單，基礎只有一張隨機生成的地圖，地圖上有牆壁和門，以及普通的地板。
玩家眼前有一個扇形光，照射到闔上的門和牆壁就會被阻斷。
玩家擁有一把槍，只能夠直線射擊，每次射擊都將發出聲音並在其他玩家的畫面上顯示紅色方向標示。

## 技術方案
使用pixi.js和peer.js實現，遊戲可以建立成網頁應用程式（可安裝），並且採用橫向屏幕，手機可以輕鬆遊玩，並設計有搖桿和按鈕來移動跟射擊。
